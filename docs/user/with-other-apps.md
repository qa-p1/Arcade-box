# Works with other Arcade apps

Enable **Connect with other Arcade apps** in Box’s Connected apps settings. Each connection can be switched off separately. An action appears only when its peer is installed, enabled, and able to handle the current result.

| App | What Box can do with it |
|---|---|
| Arcade Lens | Ask Lens to select part of the screen, recognize it, or inspect a captured image. Box keeps its own screen recorder. |
| Arcade Look | Preview supported files and results in Look instead of opening another app. |
| Arcade Clipboard | Send supported text and files to your paired devices. |
| Arcade Shelf | Add result files, folders, or text to Shelf as references. |
| Arcade Wheel | Add Box tools, presets, or saved pipelines to Wheel. |
| Arcade Find | Find can call Box tools and saved pipelines from its action list. Box does not provide a separate Find action in its own result menu. |

Box also provides tool and pipeline actions to other connected apps. Calls that send data away from this computer, run commands, or use the network can require approval. Inspect the action preview before approving.

Arcade Tools manages Box from its **Apps** tab. When Tools is running it can host the Arcade tray icon; Box uses its own tray icon otherwise.

Actions depend on the peers’ versions and platform support. See [Arcade Link](../arcade-link.md) for the current action list and behavior.
