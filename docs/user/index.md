# Arcade Box

Arcade Box brings file, media, text, web, and system tasks into one searchable desktop tool. Open it with a shortcut, find an action, and send the result where you need it.

## Three useful things to start with

- **Work with PDFs and images:** merge or split PDFs, make a scanned PDF searchable, resize or clean images, and more.
- **Convert and inspect media:** trim video, extract audio, make subtitles, or inspect files before converting them.
- **Run repeat tasks together:** save compatible actions as pipelines and start them from the same search window.

Most of Box’s tools run locally. Some tasks need an optional program already installed, a network connection, or operating-system permission. Box shows when a tool or provider is unavailable. See [Features](features.md) and [Troubleshooting](troubleshooting.md).
