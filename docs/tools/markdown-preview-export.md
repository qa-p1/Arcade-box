# Markdown / HTML Export

Renders pasted or pipeline-provided Markdown into a standalone HTML artifact. Tables, strikethrough, and task lists are supported. Embedded HTML is rendered as text; unsafe link and image schemes are removed. The output uses a restrictive content security policy and does not load remote content by default.

- **Input:** one Markdown text value.
- **Output:** a new HTML file, optionally saved into a user-selected folder.
- **Privacy:** LOCAL. No network provider is used.
- **Limit:** PDF export is not available yet.
