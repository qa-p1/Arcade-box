# Document to PDF

**LOCAL** · Requires a compatible system LibreOffice installation.

Converts supported Office/OpenDocument files through LibreOffice headless mode. Arcade Box uses a temporary isolated LibreOffice profile and writes a new PDF without overwriting the source.

Layout fidelity depends on LibreOffice, fonts, and document features. Review complex documents before relying on the result. The current form has no per-format conversion settings.
