# Images to PDF

**LOCAL** · Built in. JPEG images are embedded without re-encoding, so there is no quality loss; other formats are stored losslessly, with transparency flattened onto white.

Select and reorder image files. Choose original image-sized pages, A4, or Letter. Fixed-size pages can set orientation, image placement, and margins in millimeters. For original image-sized pages, choose an optional DPI from 72 to 600; margins on original-sized pages require an explicit DPI so their physical dimensions are defined. Without an explicit DPI, original-sized pages use 96 DPI; embedded density metadata is not used. The source images are not changed; the PDF is written beside the first selected image.

Per-image crop/fill previews and a DPI override for fixed paper sizes are not included. Accepted formats: PNG, JPEG, WebP, TIFF, BMP and GIF (first frame). Review output page sizes before printing.
