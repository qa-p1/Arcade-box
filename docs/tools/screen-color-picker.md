# Screen Color Picker

Start an interactive screen capture, select the displayed content, then sample the exact source pixel. A magnified pixel grid helps precise selection. Results include HEX, RGB, HSL, and alpha values where available.

- **Input:** a user-selected screen capture artifact.
- **Output:** structured color values.
- **Privacy:** LOCAL. The selected image is sampled on this device.
- **Platform behavior:** capture selection depends on the OS picker, portal, and screen-capture permission. Coordinates refer to capture pixels; they do not infer physical display dimensions.
