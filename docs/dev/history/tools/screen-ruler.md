# Screen Ruler / Measurement Tool

Select captured screen content and place two points to measure their distance in pixels. The shared screen-image preview magnifies the source around the pointer.

- **Input:** a user-selected screen capture artifact.
- **Output:** structured pixel width, height, and distance.
- **Privacy:** LOCAL. The selected capture is analyzed on this device.
- **Limitations:** measurements use capture pixels and do not convert to operating-system points or physical units. Capture availability and selection modes depend on OS permission and portal support.
