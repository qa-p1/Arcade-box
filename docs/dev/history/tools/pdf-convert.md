# Document to PDF

**LOCAL** · Built in; no office suite needed.

Converts Word (`.docx`), OpenDocument (`.odt`, `.odp`), PowerPoint (`.pptx`), RTF and spreadsheet (`.xlsx`, `.xlsm`, `.xlsb`, `.xls`, `.ods`) files to PDF on this device, and writes a new PDF without overwriting the source.

Text, headings, bulleted lists, bold and tables come through, in a system font embedded in the PDF (Liberation Sans, Arial, DejaVu Sans or Noto Sans). Presentations get one page per slide; spreadsheets one table per sheet, repeated headers, up to 5000 rows and 60 columns a sheet. Images, columns, colours and exact page layout are not kept, so review the result before relying on its layout. Old binary `.doc` and `.ppt` files must be saved as `.docx`/`.pptx` first.
